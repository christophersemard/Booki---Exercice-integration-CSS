## À propos

Booki reproduit une interface de recherche d'hébergements et d'activités à partir d'une maquette et d'un cahier des charges. Le travail porte sur la structure HTML, la mise en page CSS et l'adaptation aux écrans mobiles.

## Fonctionnalités

- barre de recherche ;
- filtres visuels ;
- cartes d'hébergements et d'activités ;
- mise en page responsive ;
- navigation et composants accessibles.

## Consulter localement

Aucune dépendance n'est nécessaire. Ouvrir index.html ou servir le dossier avec un serveur statique :

    python -m http.server 8000
